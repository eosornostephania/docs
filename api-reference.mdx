The Morphosis API Reference will document the endpoints, request schemas, response schemas, authentication requirements, webhook payloads, and error codes required to integrate with Morphosis.

This section is generated from the Morphosis OpenAPI specification. We are currently adding the latest engineering-confirmed specification.

Do not build against unconfirmed endpoint names, placeholder schemas, or informal examples. Production integrations should use the confirmed API Reference once it is published.

## What will be included

The API Reference will include:

- Authentication requirements

- Environment and base URL details

- Pay-in endpoints

- Payout endpoints

- Transaction status endpoints

- Webhook payload schemas

- Request examples

- Response examples

- Error codes

- Idempotency requirements

- Rate limit behavior, if applicable

## Before the API Reference is live

Operators and platform integrators can continue preparing the integration by reviewing:

- Quickstart

- Webhooks

- iGaming Quickstart

- Status

Your Morphosis contact will provide current integration details directly until the generated API Reference is published.

## Required before production

Before production traffic is approved, confirm that your team has:

- API credentials

- The correct environment details

- A configured webhook endpoint

- Duplicate webhook handling

- Reconciliation logic

- Production approval from Morphosis

- Access to the confirmed API Reference
