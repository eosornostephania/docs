Use this page to check Morphosis system availability.

\[Open Morphosis status page\]([https://status.morphosis.com](https://status.morphosis.com))

## When to use the status page

Operators, platforms, and PSPs should check the status page when:

- Investigating delayed pay-ins

- Investigating delayed payouts

- Reviewing webhook delivery issues

- Checking planned maintenance

- Reviewing incident updates

- Confirming system availability before production launch

## During an incident

If there is an active incident:

1. Check the Morphosis status page.

2. Review your internal transaction logs.

3. Compare webhook delivery against your internal records.

4. Avoid duplicate balance updates or duplicate payouts.

5. Contact your Morphosis support or onboarding channel if the issue affects production traffic.
