# Webhooks

Morphosis sends webhooks to notify your system when payment events happen.

## What webhooks are used for

Webhooks can notify your system when a transaction is created, confirmed, failed, settled, or otherwise updated.

## Idempotency

Your system should treat webhook events as idempotent.

That means if the same webhook is delivered more than once, your system should not process the same event twice.

Store the webhook event ID and ignore duplicates.
