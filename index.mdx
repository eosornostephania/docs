# Quickstart

Morphosis is licensed crypto payment infrastructure for regulated businesses.

This quickstart gives developers the basic integration path for working with Morphosis.

## Integration flow

1. Get API credentials from the Morphosis team.
2. Authenticate API requests.
3. Create a pay-in or payout flow.
4. Listen for webhook events.
5. Reconcile transaction status.
6. Move to production.

## Before you start

You will need:

- API credentials
- A configured webhook endpoint
- The correct environment details
- Approval to access production APIs

## Next steps

- Review the API reference.
- Read the webhooks guide.
- Follow the iGaming quickstart.
- Check system status.
